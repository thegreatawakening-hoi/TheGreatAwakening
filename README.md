# The Great Awakening

《The Great Awakening》是一个 Hearts of Iron IV 架空历史/世界观模组。

## 当前状态

项目目前处于初始搭建阶段。基础目录已经准备好，接下来优先落地：

1. 世界观时间线与开局日期
2. 可玩国家、国家标签与初始领土
3. 国家领导人、政体与意识形态
4. 国策树、事件链和核心机制
5. 本地化、地图与美术资源

## 目录约定

- `common/`：国策、民族精神、角色、规则、脚本效果等
- `events/`：事件链
- `history/`：国家、单位、科技与州历史
- `localisation/`：本地化文本
- `interface/`：界面定义
- `gfx/`：图标、旗帜与其他美术资源
- `music/`：音乐定义与音乐文件

## 开发约定

- 脚本 ID 使用 `tga_` 前缀，避免与原版或其他模组冲突。
- 本地化 key 使用 `tga_` 前缀。
- 重大设定和机制先写入设计文档，再实现为脚本。
